# AI Financial & Insurance Planner ── 專為台灣市場打造的 AI 財務與保單顧問 🇹🇼

> **「保大不保小、保近不保遠；大腦的人力資本，才是你終極的複利防線。」**
> 
> 本專案為 2026 iThome 鐵人賽挑戰項目。我們拒絕繁重的 AI 套件與通靈心算，採用 **「Python 精準數值引擎 + LLM 溫暖同理語意」** 的雙軌架構，打造出一個防禦力點滿的個人理財與保險規劃助手。

---

## 🌟 核心特色
- **🤖 雙引擎架構 (Dual-Engine)**：由 Python 負責 100% 精準的數學運算（複利、年金、6-3-1 現金流分配與人生隨機事件），排除 LLM 在數字上的幻覺；再由大語言模型（LLM）發揮同理心，轉譯有溫度的健檢與諮詢建議。
- **🎮 四大核心 Agent 指令**（將隨著天數陸續開放）：
  1. `/financial-check` ── **財務與防線檢測**：動態對話式蒐集收支，算出預備金防禦等級與合理保費上限。
  2. `/insurance-review` ── **保單缺口與斷捨離**：免程式碼 Markdown 萃取，快速評估保單效益並給予斷捨離強烈建議。
  3. `/life-simulate` ── **30 年人生平行時空沙盒**：無上帝視角載入近 50 年真實歷史股市/通膨報酬與隨機醫療/財務衝擊事件，挑戰是否能達成 Traditional/Coast FIRE。
  4. `/future-self` ── **來自 60 歲自己的一封信**：手刻 50 行純 Python Cosine 相似度極簡 RAG 引擎，針對玩家模擬結果，給予跨時空溫暖覆盤。
- **⚡ 零依賴 / 零套件**：不引入 LangChain、LlamaIndex 等重型框架，純 Python 標準庫，兼顧高安全性、低延遲與極佳的維護性。

## 🚀 如何開始使用？

### 1. 獨立運行 Python 引擎
如果你只想使用本專案的 Python 數值引擎進行運算，可以直接執行：

```bash
# 執行核心複利計算引擎 (Day 2 進度)
python engines.py
```

### 2. 於 OpenCode 本地環境載入 (AI 協作)
本專案專為 OpenCode Agent 平台設計。若要在本地以 AI 互動方式使用：

1. **安裝 OpenCode 終端機工具**。
2. 將本專案 clone 至本地 OpenCode 的 Skill 配置目錄下：
   ```bash
   cd ~/.config/opencode/skills/
   git clone https://github.com/1daniel3333/first-policy-ai.git first-policy
   ```
3. 將對應的 Agent 設定檔（於後續天數釋出）放入 `~/.config/opencode/agents/` 下。
4. 啟動 OpenCode，即可在對話視窗中裝備並使用此 Skill！
